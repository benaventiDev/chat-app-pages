Privacy Policy

Effective 20 September 2026

This policy describes how Workflow Alerts ("the App") handles data. The App is a private automation tool that posts operational notifications to Google Chat spaces controlled by its operator.

Information we collect

The App collects no personal information. It does not have user accounts, does not present a sign-in flow to third parties, and does not gather analytics, cookies or device identifiers.

Google user data

The App authenticates to the Google Chat API using a service account or the operator's own credentials in order to send messages to Google Chat spaces. It only writes messages; it does not read, download, store or index message history, space membership or any other Google user data. No Google user data is retained after a message is delivered.

How we use the access

Access to the Google Chat API is used solely to deliver automated notifications generated by the operator's own systems. It is never used for advertising, profiling, training machine-learning models, or any purpose unrelated to delivering those notifications.

Sharing

No data is sold, transferred or disclosed to any third party. Message content is transmitted only to Google in order to be delivered to the destination Chat space.

Limited Use

The App's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Data retention and deletion

The App maintains no database of user data, so there is nothing to retain or delete. Notification content lives only in the destination Chat space, under the control of that space's administrators.

Security

Credentials are stored as secrets in the operator's infrastructure and are not shared. All communication with Google APIs uses HTTPS.

Children

The App is not directed to children and is not accessible to the general public.

Changes

Any change to this policy will be published on this page with an updated effective date.
